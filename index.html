Voorleeshulp

Druk op de knop. Dan leest de app rustig uit wat code is.

1. Code is een plan

Code is een lijst met kleine opdrachten. De computer voert die opdrachten precies uit.

2. De volgorde is belangrijk

De computer leest van boven naar beneden. Eerst regel één. Dan regel twee. Dan regel drie.

3. Eén regel doet één ding

rechts() betekent: ga één stap naar rechts. praat() betekent: zeg iets.

4. Haakjes horen bij code

De haakjes in rechts() zeggen: doe deze opdracht nu.

5. Foutjes zijn normaal

Als je programma niet doet wat je wilde, verander je één regel en probeer je opnieuw. Dat heet debuggen.

6. Zo programmeer je

Bedenk wat je wilt maken. Schrijf kleine stappen. Druk op run. Kijk wat er gebeurt. Verbeter je code.
