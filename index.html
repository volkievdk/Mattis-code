Hoe werkt code?

Code is een plan voor de computer

De computer leest jouw code van boven naar beneden.

  1. Eén regel doet één ding.
    rechts() betekent: ga één stap naar rechts.
  2. De volgorde is belangrijk.
    De computer doet eerst regel 1, daarna regel 2.
  3. Haakjes horen bij code.
    Daarmee zeg je: doe deze actie nu.
  4. Foutjes zijn normaal.
    Je probeert, kijkt wat er gebeurt en verbetert je code.
