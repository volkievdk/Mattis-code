# Mattís Code 2.0 (React + TypeScript + Vite)

Een interactieve educatieve webapplicatie waarmee kinderen spelenderwijs leren programmeren met blokjes én echte code.

Herschreven als een moderne React + TypeScript applicatie met behoud van alle originele functionaliteiten, ontwerptokens, animaties en lesmateriaal.

## Functionaliteiten

- **Stap 0 (Gepersonaliseerd)**: Voer je eigen naam in zodat de app persoonlijke uitleg en feedback geeft.
- **Karakter kiezen**: Kies tussen Kat (🐱), Robot (🤖) of Eenhoorn (🦄) met unieke geluiden en animaties.
- **Hoe werkt code?**: Interactief uitlegscherm met spraakondersteuning (Web Speech API in het Nederlands).
- **8 Uitdagende Levels**:
  - Level 1: Volgorde (stap voor stap commando's)
  - Level 2: Herhaling (efficiënte herhaalblokjes)
  - Level 3: Debuggen (ontwijk lava en muren)
  - Level 4: Acties (praten en dansen)
  - Level 5: Blokjes worden code (visuele vertaling van blokjes naar code)
  - Level 6: Route plannen (om obstakels en water vijvers heen lopen)
  - Level 7: Sterren verzamelen (doelen in de juiste volgorde behalen)
  - Level 8: Eindbaas (knop indrukken, deur openen en ster pakken)
- **Blokjes naar Code**: Bekijk direct hoe jouw samengestelde blokjes er als echte code uitzien en stuur ze met één klik door naar het Code Lab.
- **Code Lab**: Een veilige sandbox met syntaxiscontrole en commando-chips (`rechts()`, `links()`, `omhoog()`, `omlaag()`, `praat()`, `dans()`, `openDeur()`).

## Ontwikkeling

Start de ontwikkelserver:

```bash
npm run dev
```

Bouwen voor productie:

```bash
npm run build
```
