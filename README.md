# Mattís Code v1.1

Een programmeer-app voor kinderen van ongeveer 7 jaar.

## Wat is gefixt sinds v1.0?

### Level 8

Level 8 was te ingewikkeld voor het leerdoel. In v1.1 is het een zuivere eerste if/then-les:

1. Loop naar de knop.
2. Gebruik het als-dan-blok.
3. Ga door de deur.
4. Pak de vis.

### Level 10

Level 10 was te veel tegelijk en de route was onvoldoende eerlijk. In v1.1 is het nog steeds een eindbaas, maar duidelijker:

1. Pak de ster.
2. Ga naar de knop.
3. Gebruik het als-dan-blok.
4. Ga door de deur.
5. Pak de vis.

Ook is de ster-status technisch gefixt: een gepakte ster verdwijnt nu echt.
